# Awesome League of Legends

An open-source knowledge base of curated League of Legends champion and
strategy data. Free for anyone to browse, fork, and build on.

## Contents

| Folder | What's inside |
|---|---|
| `champion-combos/` | Ability combo and trading patterns for each champion (one XML file per champion). |
| `champion-builds/` | Item and rune builds per champion and role (XML). |
| `champion-guide/`  | Champion guides: strengths, weaknesses, game plan, and power spikes (XML). |
| `playbook/`        | Macro strategy for each role — laning and early/mid/late game (plain text). |

## Using the data

Everything is plain XML and text. Clone the repo and read whatever you need:

```bash
git clone https://github.com/sorena-ai/awesome-league-of-legends.git
```
